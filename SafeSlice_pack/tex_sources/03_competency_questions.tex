\noindent A competency question is a domain question in plain English. It is not the same thing as soundness or satisfiability, those are properties of formalisms. But some of our questions are answered BY a satisfiability check under the hood, and we say so where it happens.

\section{The questions}
\begin{enumerate}[leftmargin=*, itemsep=2pt]
\item Which pizzas can anna (vegan) eat?
\item Which pizzas are safe for someone with a nut allergy?
\item Is MargheritaPizza vegetarian?
\item Which pizzas contain Milk, directly or through any ingredient chain?
\item Which pizzas can omar eat? He is halal AND nut allergic at the same time.
\item Which pizzas are spicy, and why?
\item List everything PestoSpecialePizza contains, including hidden ingredients.
\item Negative: the system must NOT report PestoSpecialePizza as nut free.
\item Negative: the system must NOT flag VeganGardenPizza as dairy unsafe (VeganCheese is not made from milk).
\item Negative: VegetarianSalamiPizza must come out impossible.
\item Negative: a pizza on NormalDough must NOT come out gluten free, whatever its toppings.
\item Tricky: an ingredient with no madeFrom information at all, is a pizza containing it safe? OWL and datalog will answer this differently, and both answers go in the report.
\item Tricky: if PorkGelatin is HalalCertified, does a pizza containing it become halal?
\item Tricky: WHY is TonnoPizza not vegetarian? Which facts and rules produce the verdict?
\end{enumerate}
